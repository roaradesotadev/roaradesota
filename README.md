# Rodrigo Arancibia: portafolio

Sitio personal de Rodrigo Arancibia, sobre automatización de procesos, datos e IA aplicada. Muestra su trayectoria como el historial de un sistema vivo: cada proyecto es un cambio fusionado, con el antes y el después del proceso.

- Next.js (App Router) en Vercel.
- El contenido está en `src/content/` (`historial.ts` y `casos.ts`). Los clientes y empleadores van anónimos por sector, y todo dato ilustrativo está rotulado como tal.
- Para trabajar en local: `npm install`, luego `npm run dev`.
